## 三、为什么可空、为什么 SET NULL、为什么不含另外三样

- **可空且无默认。**存量素材的归属是「未确认」——那和「通用」不是一回事。
  默认成通用,每张历史图会凭空成为全部颜色的共享证据;NOT NULL 则这条迁移
  在任何有存量数据的库上直接升不上去。
- **`ondelete="SET NULL"`。**删掉一个颜色不该连坐拦住素材:素材是实物样品的
  照片,颜色是业务分组。与 `products.color_variant_id` 的 RESTRICT 刻意不同 ——
  那一列删掉会让 SKU 失去身份,这一列删掉只是让图退回未归属。
- **不含**溯源列、`evidence_class` 存储列 + CHECK、新去重键。它们各自要一次
  回填或一条约束,而这一列是纯增列 —— 拆开是为了让这条能先走。
